# Timeline App – Stage 1

## 📌 Project Description

This is the static skeleton for the **Timeline App** built as part of the **Data Art** internship task.

### ✅ Features in Stage 1:

- Logo and theme toggle button in the header.
- Placeholder/filters (inside `<nav>`).
- Timeline container with `id="timeline"` for event markers.
- An empty modal with `id="modal"` for future use.
- I used Semantic HTML5 tags as per the instructions.

It was created as part of the Stage-1 task for the **Data Art internship**.

> Styling, interactivity, and timeline data will be implemented in later stages.
